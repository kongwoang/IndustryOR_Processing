# 33 — Inheritance Allocation Between Two Sons

## 1. Original Problem

A wealthy noble has died, leaving 14 items of estate (each with a monetary value). The will requires the **two Jack Russell racing dogs to stay together** (a bundle constraint). The estate must be split between **two sons so that the difference in total value between the two parts is minimized**.

| Item | Value (USD) |
|---|---|
| painting_caillebotte | 25,000 |
| bust_diocletian | 5,000 |
| yuan_vase | 20,000 |
| porsche_911 | 40,000 |
| diamond_1, diamond_2, diamond_3 | 12,000 (each) |
| louis_xv_sofa | 3,000 |
| jack_russell_1, jack_russell_2 *(bundle)* | 3,000 (each) |
| sculpture_200ad | 10,000 |
| sailing_boat | 15,000 |
| harley_davidson | 10,000 |
| cavour_furniture | 13,000 |

Total value $V_{\text{total}} = 25 + 5 + 20 + 40 + 36 + 3 + 6 + 10 + 15 + 10 + 13 = 183$ (in thousands of USD).

## 2. Sets / Indices

- $\mathcal{I} = \{1, \dots, N\}$ — set of items, $N = 14$.
- $\mathcal{R} = \{1, \dots, R\}$ — set of recipients, $R = 2$.
- $\mathcal{B} = \{1, \dots, B\}$ — set of inseparable bundles, $B = 1$ (the dog pair).
- $\mathcal{M}_b \subseteq \mathcal{I}$ — set of items belonging to bundle $b$.

## 3. Parameters

| Symbol | Shape | Description |
|---|---|---|
| $v_i$ | $N$ | Value of item $i$ |
| $\mathcal{M}_b$ | — | Members of bundle $b$ |

## 4. Decision Variables

| Symbol | Domain | Shape | Description |
|---|---|---|---|
| $x_{i,r}$ | $\{0,1\}$ | $N \times R$ | $=1$ if item $i$ goes to recipient $r$ |
| $y_{b,r}$ | $\{0,1\}$ | $B \times R$ | $=1$ if bundle $b$ goes to recipient $r$ |
| $V_r$ | $\mathbb{R}_{\ge 0}$ | $R$ | Total value received by recipient $r$ |
| $\Delta$ | $\mathbb{R}_{\ge 0}$ | scalar | Maximum value imbalance among parts |

## 5. Objective Function

$$
\min \; \Delta.
$$

## 6. Constraints

**(C1) Each Item Goes to Exactly One Recipient:**

$$
\sum_{r=1}^{R} x_{i,r} \;=\; 1 \qquad \forall i \in \mathcal{I}.
$$

**(C2) Each Bundle Goes to Exactly One Recipient:**

$$
\sum_{r=1}^{R} y_{b,r} \;=\; 1 \qquad \forall b \in \mathcal{B}.
$$

**(C3) Bundle Integrity (every item in a bundle follows the bundle):**

$$
x_{i,r} \;=\; y_{b,r} \qquad \forall b \in \mathcal{B},\, \forall i \in \mathcal{M}_b,\, \forall r \in \mathcal{R}.
$$

**(C4) Total Value per Recipient:**

$$
V_r \;=\; \sum_{i \in \mathcal{I}} v_i\, x_{i,r} \qquad \forall r \in \mathcal{R}.
$$

**(C5) Imbalance Definition (linearization of $|V_r - V_{r'}|$):**

$$
\Delta \;\ge\; V_r - V_{r'} \qquad \forall r, r' \in \mathcal{R}.
$$

(When $r, r'$ range over all ordered pairs, this implicitly includes the reverse direction $V_{r'} - V_r \le \Delta$, so a second inequality is unnecessary.)

**(C6) Domains:**

$$
x_{i,r} \in \{0,1\},\quad y_{b,r} \in \{0,1\},\quad V_r \ge 0,\quad \Delta \ge 0.
$$

## 7. Note for the $R = 2$ Case

With two recipients, the model can be simplified using $x_i \in \{0,1\}$ (1 = first son, 0 = second son), with:

$$
\Delta \;=\; \left| \sum_i v_i\, x_i - \sum_i v_i\,(1 - x_i) \right| \;=\; \left| \, 2\sum_i v_i x_i - V_{\text{total}} \, \right|.
$$

The problem becomes the classic **partition problem**. The general formulation in §6 still applies for any $R \ge 2$.
