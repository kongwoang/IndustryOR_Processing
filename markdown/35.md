# Index 35 — Permutation Flow Shop for Fabric Dyeing

## 1. Original Problem (questions_txt/35.txt)

A dyeing plant has 3 vats. Each batch of fabric must be dyed sequentially in the order **vat 1 → vat 2 → vat 3**. There are 5 batches with the processing-time matrix $p_{i,j}$ (in hours):

$$
P =
\begin{pmatrix}
3 & 1 & 1 \\
2 & 1.5 & 1 \\
3 & 1.2 & 1.3 \\
2 & 2 & 2 \\
2.1 & 2 & 3
\end{pmatrix}
$$

Goal: choose a processing order for the batches and a start time on each vat to minimize the **makespan** $C_{\max}$.

→ This is a **Permutation Flow Shop** problem with $N = 5$ jobs and $M = 3$ machines (vats).

## 2. Sets / Indices

- $\mathcal{I} = \{1, \dots, N\}$ — set of batches.
- $\mathcal{J} = \{1, \dots, M\}$ — set of vats (in fixed technological order).

## 3. Parameters

| Symbol | Shape | Description |
|---|---|---|
| $p_{i,j}$ | $N \times M$ | Processing time of batch $i$ in vat $j$ |
| $\mathrm{BigM}$ | scalar | A large constant for linearizing the disjunction; e.g., $\mathrm{BigM} = \sum_{i,j} p_{i,j}$ |

## 4. Decision Variables

| Symbol | Domain | Shape | Description |
|---|---|---|---|
| $s_{i,j}$ | $\mathbb{R}_{\ge 0}$ | $N \times M$ | Start time of batch $i$ on vat $j$ |
| $c_{i,j}$ | $\mathbb{R}_{\ge 0}$ | $N \times M$ | Completion time of batch $i$ on vat $j$ |
| $z_{i,i'}$ | $\{0,1\}$ | for all $i < i'$ | $=1$ if batch $i$ precedes batch $i'$ in the common processing sequence |
| $C_{\max}$ | $\mathbb{R}_{\ge 0}$ | scalar | Makespan |

> *Because this is a permutation flow shop, the ordering variable $z_{i,i'}$ has no $j$ index — the same order applies to every vat.*

## 5. Objective Function

$$
\min \; C_{\max}.
$$

## 6. Constraints

**(C1) Completion = Start + Processing Time:**

$$
c_{i,j} \;=\; s_{i,j} + p_{i,j} \qquad \forall i \in \mathcal{I},\, \forall j \in \mathcal{J}.
$$

**(C2) Technological Order Within a Batch:**

$$
s_{i,j} \;\ge\; c_{i,j-1} \qquad \forall i \in \mathcal{I},\, \forall j \in \mathcal{J} \setminus \{1\}.
$$

**(C3) No Overlap on the Same Vat (disjunctive, sharing the ordering variable $z$):**

For every pair $i < i'$ in $\mathcal{I}$ and every vat $j \in \mathcal{J}$:

$$
\begin{aligned}
s_{i',j} \;&\ge\; c_{i,j} \;-\; \mathrm{BigM}\,(1 - z_{i,i'}), \\[2pt]
s_{i,j}  \;&\ge\; c_{i',j} \;-\; \mathrm{BigM}\, z_{i,i'}.
\end{aligned}
$$

(If $z_{i,i'} = 1$: $i$ precedes $i'$ on every vat. If $z_{i,i'} = 0$: $i'$ precedes $i$ on every vat. This is exactly the "permutation" property — the same order on every vat.)

**(C4) Makespan Definition:**

$$
C_{\max} \;\ge\; c_{i,M} \qquad \forall i \in \mathcal{I}.
$$

(Imposing the constraint only on the last vat $M$ is sufficient; for $j < M$ we always have $c_{i,j} \le c_{i,M}$ via (C2).)

**(C5) Domains:**

$$
s_{i,j}, c_{i,j} \ge 0,\quad z_{i,i'} \in \{0,1\},\quad C_{\max} \ge 0.
$$

## 7. Recovering the Permutation $\pi$

After solving, define:
$$
\text{rank}(i) \;=\; 1 + \sum_{i' < i} (1 - z_{i',i}) + \sum_{i' > i} z_{i,i'},
$$
then $\pi$ is the batches sorted in increasing $\text{rank}(i)$.

(A simpler equivalent: sort batches by $s_{i,1}$ in ascending order.)
